# McDermott AI Prompting Affordances
How users discover what they can do with the AI. The blank input is the worst onboarding screen ever made.

## The discovery principle
Don't make users guess. Show them — examples, templates, suggestions, persistent affordances around the input.

## Empty state for chat surfaces
**Anatomy:** brief intro line (one sentence on what this assistant does), 3–5 suggested prompts as tappable cards or chips, optional "Try asking" rotation that swaps suggestions every few seconds.

**Suggested prompt rules:**
- Representative of common use cases — not the full capability list.
- Phrased as actual sendable prompts ("Summarize my last meeting" not "Summarization").
- Diverse — cover read, write, analyze, generate.
- Adapt over time as user history accumulates.
- Always dismissible — power users don't need them after the first session.

**Visual:** cards or pills above/below the input. On pale empty-state surfaces (e.g., `--color-pale-blue`), chips use `--bg-surface` with `--text-primary` so they stay theme-aware. Hover/focus: border AND text both flip to `--accent-interactive` — border-only is incomplete. Click sends immediately.

## Slash commands
For products with structured commands or templates.
- Triggered by `/` at the start of the input.
- Filterable popover anchored to the input.
- Commands grouped by category with description and shortcut.
- Arrow keys navigate, Enter selects, Escape closes, Tab autocompletes the highlighted command.

**Command palette (Cmd/Ctrl+K)** is the broader version — searches commands, recent prompts, files, contacts. See `navigation-and-ia.md`.

## File upload
- Phosphor `paperclip` icon to the left of the send button.
- Drag-and-drop on the input or chat area triggers upload.
- Uploaded files appear as chips above the input: name, size, file-type icon, remove (`x`).
- Show upload progress and extraction state ("Extracting text from PDF…").
- File-type/size limits visible before upload — never error after upload completes.

## Image input
Same paperclip affordance. Thumbnails above the input. "Extracting text…" for OCR. For visual reasoning, the AI reflects what it's "looking at" in its response.

## Voice input
- Phosphor `microphone` icon button.
- On press, record with visible waveform / level indicator and elapsed time inline.
- Tap to stop and transcribe.
- Show transcript before sending — let the user edit. Allow keyboard editing.

## Prompt history
Up arrow in the input recalls the previous prompt (shell-style). Cmd/Ctrl+K opens the command palette with searchable history. Persistent side-panel history for products where revisiting prompts is common.

## Templates
For repeated workflows.
- "Save as template" after a successful prompt.
- Templates surface in the empty state and via slash command.
- Variables: "Summarize {document} in {style} style." Inline form fills variables before send.

## Context indicators
Show what context the AI has access to: "Connected to: your inbox, calendar, design system." (chip group above input). Click a chip to disconnect. "+ Add context" button. This is how users develop accurate mental models of what the AI can see.

## Conversation forking
"Branch from here" action on any user message. Creates a new conversation pre-populated with history up to that point. Useful for exploring alternative directions without losing the main thread.

## Multi-turn affordances
After a response: 2–3 follow-up suggestion chips below ("Tell me more", "Show an example", "Summarize this"). Generated by the model based on conversation, not hardcoded. Always dismissible.

## McDermott-specific
Suggested-prompt cards: `--color-pale-blue` background, 1px `--border-light`, 2px radius, navy text (theme-stable). Slash-command popover: `--bg-surface`, `--shadow-md`, McDermott popover from `disclosure-surfaces.md`. File chips: pill-shape, `--color-pale-blue` fill, navy text (client-facing). Voice waveform: `--color-teal` bars. Context chips: pill-shape with leading icon — connected = `--color-pale-blue`, disconnected = transparent + `--border-light`.

## Mobile
- Suggested-prompt chips: wrap to multiple rows — never horizontal scroll. Max 3 per row at <480px.
- Slash popover: `min(90vw, 360px)`, anchored at input position.
- Command palette: full-screen sheet on mobile, not inline overlay. Triggered by search icon in top bar or long-press on input.
- Paperclip stays in the input row — too frequent to hide in overflow.
- Voice input: respect platform recording UX (Android needs supplemented indicator).
- File/image previews: thumbnail row wraps above input, never horizontally scrolls.
- Context chips: collapse to "+ Connected to 3 sources"; tap expands the full list.
- Empty-state prompts: single column with comfortable tap targets, not crammed in a grid.

See `responsive-and-mobile.md` for the universal checklist.

## Anti-patterns
- Blank input with no examples
- Surface every capability in the empty state (overwhelming)
- Suggested prompts that aren't actually sendable
- Slash commands without keyboard navigation
- File upload that errors on unsupported types after upload (surface limits before)
- Voice input that submits immediately without transcript review
- Hide the connected context (creates "what does it know" anxiety)
- Persistent suggestions that can't be dismissed
- Templates without variables
- Modal popup explaining how to use the AI on first visit
- Auto-rotating suggestions changing faster than ~4s
- "Smart" suggestions generated by another model that take 2s to appear
- Drag-and-drop upload with no visual feedback during drag
