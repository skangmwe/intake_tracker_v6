# Form

## What belongs here

Form inputs — TextField, TextArea, NumberField, DateField, Select, MultiSelect, Checkbox, Radio, Toggle, SegmentedControl.

## What does not belong here

Feature-specific components. Anything that reaches into a specific module's state.

## Notes

Every input root sets data-ds="input" (or the specific type). Fields must fill their cell — width: 100%, min-width: 0.
